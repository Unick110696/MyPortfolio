# 🌐 Developer Portfolio - Nikko Delfin

Welcome to the repository for my personal portfolio website! This project serves as a digital showroom for my work, skills, and professional journey as a **Web & Systems Developer**.

## 🚀 About the Project

This portfolio is designed to be clean, modern, and highly responsive. It acts as a central hub where clients and employers can explore my expertise in building robust web applications, management systems, and high-performance websites.

### ✨ Key Features
*   **Modern Hero Section:** A sleek intro with an eye-catching, glowing profile design.
*   **Smooth Navigation:** Section-based routing for Home, Skills, Projects, and Contact.
*   **Fully Responsive:** Optimized for all screen sizes, from mobile devices to large desktop monitors.
*   **Call-to-Action Buttons:** Direct links for users to view my work or get in touch immediately.
